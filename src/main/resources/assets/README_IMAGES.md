# Куда положить свои картинки

В этом репозитории PNG-файлы не хранятся (чтобы не было ошибки при push про бинарные файлы).

Перед запуском мода положи свои изображения по путям:

- `src/main/resources/assets/minecraft/textures/gui/title/minecraft.png` — логотип на главном меню
- `src/main/resources/assets/minecraft/textures/gui/title/mojangstudios.png` — картинка загрузки вместо Mojang
- `src/main/resources/assets/e4menu/textures/gui/main_menu_background.png` — плоский фон главного меню
