# Possessive (Fabric)

Мод добавляет переключаемый режим полёта сквозь блоки (no-clip).

## Что делает
- Клавиша **G** включает/выключает no-clip.
- В режиме no-clip игрок может летать сквозь стены.

## Сборка
> Примечание: Minecraft `1.21.11` официально не существует в ветке 1.21.x, поэтому проект настроен на `1.21.1`.

```bash
JAVA_HOME=$HOME/.local/share/mise/installs/java/21.0.2 gradle build
```

Готовый jar ожидается в `build/libs/`.

## Важно
- Это клиентская логика и может не работать на серверах с античитом.
- Проверяй правила сервера перед использованием.

## Структура
- `PossessiveClient` — обработка клавиши и режим no-clip.
- `EntityNoClipAccessor` — accessor mixin для поля `noClip`.
