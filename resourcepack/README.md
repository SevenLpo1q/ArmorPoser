# E4 Resource Pack (Minecraft 1.21.11)

Это **ресурспак**, не мод.

Меняет только:
- логотип `Minecraft` в главном меню;
- логотип загрузки `Mojang Studios`.

Фон главного меню **не меняется** (как ты и попросил).

## Куда положить картинки

Положи свои PNG сюда:

- `resourcepack/assets/minecraft/textures/gui/title/minecraft.png` — 1-я картинка (логотип главного меню)
- `resourcepack/assets/minecraft/textures/gui/title/mojangstudios.png` — 2-я картинка (логотип загрузки)

PNG не коммитятся в репозиторий (из-за ограничений на binary files), добавляй их локально.

## Как установить

1. Заархивируй содержимое папки `resourcepack/` в zip (в корне zip должны быть `pack.mcmeta` и папка `assets`).
2. Положи zip в `%appdata%/.minecraft/resourcepacks`.
3. Включи ресурспак в игре.
